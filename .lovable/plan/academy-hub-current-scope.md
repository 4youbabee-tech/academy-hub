# Academy Hub — Current Scope

هذا الملف هو المرجع الوحيد لنطاق المشروع الحالي. أي خطة أقدم تتعارض معه تُعد ملغاة.

## المبدأ

واجهة بسيطة للموظف، مع قواعد مالية وتاريخية قوية داخل منطق البيانات.

التدفق: طالب → دورة بسعر → صف → تسجيل → فاتورة → سند قبض → تحديث الملف وDashboard والتقارير.

## الوحدات المعتمدة

- الطلاب والأرشفة والاسترجاع.
- الدورات والصفوف والتسجيلات.
- الإيصالات والفواتير في مركز مالي واحد.
- المصاريف والمداخيل الجانبية المستقلة.
- الموظفون والرواتب والسلف.
- المستخدمون والصلاحيات وسجل التدقيق.
- التقارير والنسخ الاحتياطي والإعدادات.

## وحدات ملغاة نهائيًا

لا تُضف الحضور أو العلامات أو الامتحانات أو الشهادات أو أوزان التقييم إلى الواجهة أو الصلاحيات أو التقارير أو قاعدة البيانات.

## قواعد غير قابلة للتجاوز

- لا يُحذف الطالب؛ يُؤرشف، ويُمنع ذلك عند وجود تسجيل نشط.
- لا تتغير دورة صف بعد وجود أي تسجيل عليه.
- الفواتير والإيصالات والمصاريف الملغاة تبقى للتدقيق وتُستبعد من الإجماليات.
- سندات قبض الطلاب لا تُكرر داخل المداخيل الأخرى.
- القبض لا يتجاوز رصيد الفاتورة.
- السلفة تخفض صافي الدفعة، لكنها لا تخفض تكلفة الراتب.
- المدير لا ينشئ أو يدير Owner، ولا يمكن حذف أو تعطيل آخر Owner.
- تواريخ التقارير اليومية والشهرية تُحسب بالتاريخ المحلي للجهاز.

## المسار التقني

الحالي: React + TypeScript + TanStack Router + IndexedDB.

المستقبل بعد التثبيت: React → Electron IPC → Repository/Data Access → SQLite → Backup/Migrations → Offline signed licensing → Windows releases.
